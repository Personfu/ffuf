# Authorized Fuzzing Harness Notes

This fork should be documented as a learning and authorized testing reference. Fuzzing is useful when it is scoped, rate-limited, logged, and pointed only at systems you own or are explicitly authorized to test.

## Pre-flight checklist

- Written authorization or owned lab target.
- Target host and route allowlist.
- Rate limit chosen and documented.
- Wordlist source documented.
- Stop condition defined.
- Logs saved for reporting.
- No credential stuffing, harassment, or public-target spray.
